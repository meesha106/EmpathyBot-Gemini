# EmpathyBot-Gemini
Create a .env file in the project folder containing GEMINI_API_KEY=your_key.

## Tech stack
Python, Gemini API, FAISS, HTML/CSS/JS

## Setup
1. Clone the repo
2. python -m venv venv, then activate it
3. pip install -r requirements.txt
4. Copy .env.example to .env and add your Gemini API key
5. Download the source PDFs from drive or the link provided and place them in the project folder
6. python info_conversion.py
7. python server.py
